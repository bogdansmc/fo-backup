fo-backup privacy policy

fo-backup is a private backup tool used only by its owner, for the owner's own Google account.

What it accesses

With the owner's permission, fo-backup reads files and file metadata in the owner's Google Drive using the read-only scope https://www.googleapis.com/auth/drive.readonly. It cannot modify or delete Drive content.

What it does with the data

Files are copied only to storage that the owner controls: an encrypted disk on the owner's own server, and an encrypted offsite backup. The data is used only to keep a backup copy for the owner.

Sharing

No data is sold, shared with, or disclosed to any third party. No analytics, advertising, or tracking is used.

Google API data

fo-backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

Backup copies are kept for as long as the owner keeps them. Access can be revoked at any time at myaccount.google.com/connections, after which fo-backup can no longer read the Drive.

Contact

Questions: use the support email shown on fo-backup's Google sign-in screen.
